Cross-toolchain ABI fingerprints

What each cross toolchain's binaries need at runtime (loader, libc soname, ISA, endianness, float ABI) — so you can pick one that matches your target without deploying to find out.

Pulls the interp from a program interpreter: line and adds every soname it finds (NEEDED […] entries and bare *.so* tokens) to provides. Paste from a target-native binary — its needed libs are ones the target genuinely has.
A row is OK if its interp is your loader and every needed lib is provided. It's RISKY when a hardened/large build could still pull the toolchain's ldso_soname, which your target doesn't list (this is the classic ld-uClibc.so.1 vs .so.0 trap). NO = wrong loader or a missing library.

Dataset: fingerprints.json, generated by fingerprint-dir.sh + probe-toolchain.sh. source repo.
